## Portfolio scope

The website intentionally uses only experience, projects, tools, education, publication, certification, and quantitative results documented in the current résumé.

### Featured implementation work

- **7nm ARM-based CPU Core — Synopsys Tokyo**
  - 3.5M+ instances
  - 350+ macros
  - 2.54 GHz pre-DFT / 2.47 GHz post-DFT
  - Floorplan exploration, timing sensitivity studies, routing optimization, setup closure, DFT timing constraints, timing ECOs, TCL automation

- **28nm ARM Core — ZOICX Technologies**
  - 300K+ gates
  - 29 macros
  - 500 MHz target achieved
  - Synthesis, physical design, equivalence verification, floorplan and congestion optimization

- **28nm Synthesis-to-Post-Route Design — RiseTime Semiconductor**
  - 72K gates
  - 6 macros
  - 2 clocks
  - 454 MHz
  - Synthesis, floorplanning, placement, CTS, routing and timing checks

- **ALU Design — RTL to GDSII**
  - Academic physical-design project completed during the Post Graduate Diploma in Physical Design
